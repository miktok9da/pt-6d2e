## 📦 How to Upload to GitHub

### Method 1: Drag & Drop (Easiest)

1. **Open File Explorer** → Go to your project folder
2. **Select ALL files and folders** (Ctrl+A)
3. **Go to GitHub.com** → Create new private repo
4. **Drag and drop** everything into GitHub

### Method 2: ZIP Upload

1. **Right-click** on project folder
2. **Send to** → **Compressed (zipped) folder**
3. **Upload ZIP** to GitHub
4. **Extract** in GitHub
